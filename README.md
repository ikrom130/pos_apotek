# POS Apotek

POS apotek berbasis PHP native, MySQL, vanilla JavaScript, dan Tailwind CSS.

> Status: pengembangan lokal. Fitur yang belum tercantum sebagai selesai masih dalam tahap belajar dan implementasi.

## Teknologi

- PHP melalui Laravel Herd
- MySQL
- Vanilla JavaScript
- Tailwind CSS
